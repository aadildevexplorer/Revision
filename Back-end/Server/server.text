Backend Basics (Node.js + Express)

1. Server kya hota hai aur kyu banate hain

Server ek program hota hai jo client (browser, React app, mobile app,
Postman) se aane wali HTTP requests ko receive karta hai aur unko
response bhejta hai.

Simple flow: Client → Request → Server (Node.js + Express) → Processing
/ Database → Response

Agar server nahi hoga to: - API endpoints exist nahi karenge - client
request handle nahi hogi - database se data fetch nahi hoga

Example Express server:

const express = require(“express”); const app = express();

app.get(“/”, (req, res) => { res.send(“Server is running”); });

app.listen(5000, () => { console.log(“Server started on port 5000”); });

Short line: Server client ki request ko handle karta hai aur response
bhejta hai.

------------------------------------------------------------------------

2. package.json scripts kya hoti hain

Example:

“scripts”: { “dev”: “nodemon ./server.js”, “start”: “node
./backend/server.js” }

Scripts basically predefined commands hoti hain jo npm run se execute hoti hain.

------------------------------------------------------------------------

3. npm run dev kya karta hai
npm run dev npm script command hai jo package.json ke scripts section me define hoti hai.

npm run dev ka use kya hai

Use: development ke time server run karne ke liye.

Command: npm run dev

Ye run karta hai: nodemon ./server.js

Nodemon ka kaam: - agar code change hota hai to server automatically
restart ho jata hai

Isliye development me nodemon use hota hai.

------------------------------------------------------------------------

4. npm start kya karta hai

Command: npm start

Ye run karta hai: node ./backend/server.js

Isme: - normal node run hota hai - automatic restart nahi hota - mostly
production me use hota hai

------------------------------------------------------------------------

5. Development vs Production

Development: Jab developer application bana raha hota hai, testing aur
debugging kar raha hota hai.

Example: npm run dev

Production: Jab application live ho jati hai aur real users use karte
hain.

Example: npm start

Short difference: Development = build + testing phase Production = live
users phase

------------------------------------------------------------------------

6. dependencies vs devDependencies

dependencies: Wo packages jo application run karne ke liye production me
bhi required hote hain.

Examples: - express - mongoose - jsonwebtoken

Install: npm install express

devDependencies: Wo packages jo sirf development ke time use hote hain.

Examples: - nodemon - eslint - prettier

Install: npm install nodemon –save-dev

Short difference: dependencies → app run karne ke liye devDependencies →
development tools
